# Case File 1: Orientation Server

Four years ago, Halcyon Dynamics' internal auditor Priya Okonkwo-Reyes
disappeared mid-investigation into a shell-company network she called "the
Ferryman." She left behind a numbered set of case files — one per system she
had flagged as worth another look.

Case File 1 is the simplest one: a temporary onboarding server for new
contractors, spun up years ago and never properly decommissioned. IT ticket
IT-4417, still open, requesting it be locked down. Nobody ever closed it.

A contractor named **J. Miller** was the last person provisioned on this box.
Priya's notes say she found everything she needed here "in an afternoon" —
and that it was enough to point her at Case File 2.

You've been hired to pick up where she left off. Start with what's public.
